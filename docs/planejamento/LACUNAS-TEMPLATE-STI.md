# LACUNAS DO TEMPLATE STI E PENDÊNCIAS (H)

## Itens com decisão "H" (Homologação Pendente)

1. **LAT-F012 — VLibras**
   - **Pergunta:** O widget oficial do VLibras é obrigatório na nova versão ou vídeos em Libras bastam?
   - **Responsável:** STI + LATECE.
   - **Impacto:** Se obrigatório, precisamos incluir um plugin no Nuxt.

2. **LAT-F013 — Header/Footer/Menu**
   - **Pergunta:** Quais são os componentes exatos do template UFRN para cabeçalho e rodapé?
   - **Responsável:** STI.
   - **Impacto:** Não podemos codificar o layout sem o arquivo do template.

3. **GOV-PEN-004 — Gestão de Conteúdo (CMS vs API Própria)**
   - **Pergunta:** O backend da nova versão usará API própria + PostgreSQL (como no Nuxt original) ou consumirá um CMS institucional?
   - **Responsável:** STI + LATECE.
   - **Impacto:** Bloqueia a implementação do Admin (LAT-F008), Notícias (LAT-F006), Equipe (LAT-F003) e Equipamentos (LAT-F004).

4. **GOV-PEN-003 — Uso da Marca LATECE**
   - **Pergunta:** Onde o logotipo do LATECE pode ser aplicado dentro do template institucional?
   - **Responsável:** STI + Coordenação LATECE.
