# INVENTÁRIO DE COMPONENTES INSTITUCIONAIS (PREVISTOS)

*Nota: Este inventário é baseado nas capturas de tela enviadas e nas diretrizes da STI. Deverá ser atualizado quando o código-fonte do template for entregue.*

## 1. Componentes Globais Esperados
- **Header (Cabeçalho):**
  - Barra superior (governo/federal).
  - Área do logo UFRN.
  - Menu de navegação principal.
  - Seletor de idiomas (PT/EN).
- **Footer (Rodapé):**
  - Logotipo da UFRN.
  - Endereço institucional.
  - Links úteis e redes sociais.
- **Breadcrumbs:**
  - Navegação estrutural (ex: Início > Equipe).

## 2. Componentes de UI Esperados
- **Botões:** Primário, Secundário, Outline (respeitando o azul UFRN).
- **Cards:** Para notícias, publicações e membros da equipe.
- **Formulários:** Inputs, Selects e Textareas com foco visível e erro claro.
- **Tabelas/Listas:** Para dados tabulares (ex: publicações).
- **Modais/Diálogos:** Para exibição de detalhes de equipamentos.
- **Alertas/Notificações:** Feedback de sucesso, erro ou aviso.

- **VLibras:** Componente flutuante (padrão do governo).
