# GUIA DE EXECUÇÃO LOCAL (PREPARATÓRIO)

Este guia será usado **apenas após a STI liberar o template e as versões**. Para sua segurança, não execute estes comandos agora no projeto antigo.

## 1. Quando o Template Chegar
O template da STI provavelmente virá como um arquivo `.zip` ou um link de repositório Git.
1. Extraia o template em uma **nova pasta** (ex: `latece-sti-compliance`).
2. Abra o VS Code nesta nova pasta.
3. Abra o terminal (Ctrl + ').
